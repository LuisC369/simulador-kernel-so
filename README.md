# Simulador de Funciones del Kernel

Proyecto final de Sistemas Operativos I, Universidad Mariano Gálvez.

Simula en JavaScript la planificación de procesos, la gestión de memoria, la sincronización con semáforos y el manejo de interbloqueos.

## Requisitos

- Node 18 o superior
- Git

## Interfaz web

```powershell
npm run web
```

Después abrir http://localhost:3000 en el navegador.
